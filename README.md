# Base UI Drawer

DEMO https://base-ui-drawer-ios-repro.vercel.app/

The [Virtual keyboard aware example](https://base-ui.com/react/components/drawer#virtual-keyboard-aware)
from Base UI 1.8.0, with only the Name field and no footer.
The drawer sizes to its content and keeps the original demo's animations and component styles.
Keyboard handling uses the unmodified `Drawer.VirtualKeyboardProvider` from Base UI.

```sh
npm install
npm run dev
```

Vite exposes both localhost and a local network address for testing on a phone.

```sh
npm run build
npm run lint
```
